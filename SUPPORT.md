# Support

OpenConstraint is community-supported software. There is no service-level
agreement or guarantee of response time.

## Where to ask

- Usage and design questions: GitHub Discussions, once enabled.
- Reproducible defects: use the relevant GitHub issue form.
- Documentation corrections: open a documentation issue or pull request.
- Vulnerabilities: follow [SECURITY.md](SECURITY.md); never file a public issue.

Please search existing issues first. Include the OpenConstraint version, Python
version, operating system, exact command, and a minimal synthetic or redacted
reproducer. Do not upload proprietary netlists, Liberty libraries, SDC files,
or PDK data.

## Supported releases

During the 0.x beta, only the newest minor release receives routine fixes. A
critical security correction may be backported when practical. Support status
is independent of any optional OpenSTA version; see
[docs/compatibility.md](docs/compatibility.md).

## Commercial and sign-off use

OpenConstraint can be useful in an internal quality gate, but the project does
not certify constraints, replace engineering review, or provide timing sign-off
assurance. Organizations remain responsible for validating their flows and
results.
