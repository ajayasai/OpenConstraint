# OC2003 — clock-redefined

**Default severity:** error

**Category:** clocks

Reports a clock name defined more than once without a clean additive merge.

The emitted severity is error when period or targets conflict and warning when
the repeated definitions are structurally identical. Use one authoritative
definition, or use `-add` only for an intentional additive target merge.
Evidence points to the prior definition.

The beta compares modeled period and target sets. It does not fully reproduce
vendor command precedence or compare every clock property, so review waveform
and other options independently.
