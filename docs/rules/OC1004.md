# OC1004 — unsupported-query

**Default severity:** warning

**Category:** queries

Reports a non-dynamic object query that the beta cannot resolve, such as an
invalid regular expression or a filter outside the documented simple direction
and sequential-cell forms.

Rewrite the query using the supported subset or provide a minimal synthetic
fixture in a compatibility request. Review every dependent constraint manually;
OpenConstraint does not guess the intended collection.

OC1004 is distinct from OC1001: unsupported means the resolver cannot determine
the answer, while zero-object-query means the supported resolver determined
that the answer is empty.
