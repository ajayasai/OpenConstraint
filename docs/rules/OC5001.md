# OC5001 — mode-clock-drift

**Default severity:** note

**Category:** modes

Reports a clock that is missing from a mode or differs across modes in modeled
period, waveform and explicitness, target set, primary/generated
classification, source/master relationship, or generated transform fields.

Mode-specific clocks are common. Review the per-mode evidence, confirm every
difference is intentional, and keep the rationale under version control.

The generated transform signature includes divide, multiply, duty cycle,
invert, combinational, edges, and edge shifts. The comparison still covers only
the normalized fields and modes supplied in one invocation; it does not include
every SDC clock property or discover scenarios from external flow configuration.
