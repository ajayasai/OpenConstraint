# OC5001 — mode-clock-drift

**Default severity:** note

**Category:** modes

Reports a clock that is missing from a mode or differs across modes in modeled
period, target set, or primary/generated classification.

Mode-specific clocks are common. Review the per-mode evidence, confirm every
difference is intentional, and keep the rationale under version control.

The comparison currently does not include waveform, source, master, or every
clock option. It compares only modes supplied in one invocation; it does not
discover scenarios from external flow configuration.
