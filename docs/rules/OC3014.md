# OC3014 — io-delay-overwritten

**Default severity:** warning

**Category:** I/O

Reports a later finite I/O delay that reuses an earlier relationship without
`-add_delay`. A relationship overlaps when delay kind, port, resolved clock set,
and clock edge are the same and their min/max and rise/fall scopes intersect.
Evidence identifies the intersecting slots and the previous source location.

Remove the duplicate, narrow one scope, or use `-add_delay` when multiple
relationships are intentional. `-add_delay` on the later command suppresses
this overwrite finding for that command.

The rule models replacement by normalized static slots. It does not reproduce
every vendor precedence rule, Tcl collection mutation, or path-specific timing
semantics.
