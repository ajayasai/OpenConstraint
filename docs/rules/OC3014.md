# OC3014 — io-delay-overwritten

**Default severity:** warning

**Category:** I/O

Reports a later finite I/O delay that replaces active earlier intent without
`-add_delay`. Within the same delay kind and port, a non-additive command
replaces intersecting min/max by rise/fall slots in its own clock/edge
relationship and removes every competing clock or clock-edge relationship.
Evidence identifies the removal reason and each exact prior slot, value, and
source location without implying a rectangular scope that was not active.

Remove the duplicate, narrow one scope, or use `-add_delay` when multiple
relationships are intentional. `-add_delay` on the later command suppresses
this overwrite finding for that command.

The rule replays normalized static slots using the same active-state model used
for coverage and effective-SDC comparison. Superseded relationships do not
produce stale min/max-completeness warnings. The model does not reproduce every
vendor precedence rule, Tcl collection mutation, or path-specific timing
semantics.
