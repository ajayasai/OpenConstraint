# OC3012 — io-delay-direction

**Default severity:** error

**Category:** I/O

Reports `set_input_delay` targeting an output-only port or `set_output_delay`
targeting an input-only port. Inout ports are valid targets for both commands.

Correct the port collection or use the matching delay command. Wrong-direction
targets are removed from the normalized delay record and do not satisfy the
corresponding input/output coverage obligation.

Direction comes from the modeled structural top-level port declaration. An
incomplete or incorrectly elaborated netlist can therefore affect this result
and is separately gated by `OC0002` when parser/elaboration warnings exist.
