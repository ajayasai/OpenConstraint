# OC2011 — generated-clock-master-invalid

**Default severity:** error

**Category:** generated clocks

Reports a generated clock whose resolved source is not reachable from an
eligible modeled master clock. If `-master_clock` is present, the relationship
must resolve specifically to that named clock.

Fix `-source`, `-master_clock`, the primary clock target, or the structural
clock path. The HTML graph can make the modeled relationship easier to inspect.

Reachability is topological rather than timing-arc accurate. Unsupported
assignments, gating conditions, case analysis, or Liberty functions can cause a
modeled relationship to differ from a sign-off tool.
