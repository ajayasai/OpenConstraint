# OC0002 — incomplete-structural-model

**Default severity:** error

**Category:** loading

Reports that Verilog parsing, Liberty parsing, or hierarchical elaboration
produced one or more warnings. These warnings mean that structural input was
ignored, inferred, malformed, or truncated, so object resolution, clock
propagation, endpoint coverage, and exception analysis may be incomplete.

The finding is design-wide and emitted once per audit, including multi-mode
audits. Its evidence records the total warning count, the first 50 warnings in
deterministic parser order, and the number omitted from that sample. The full
backward-compatible warning list remains available as
`design.parser_warnings` in machine-readable reports.

Resolve every warning before treating an audit as a quality gate. Use a
supported synthesized structural netlist, provide complete Liberty metadata for
every instantiated cell type, and reduce inputs that cross documented parser or
elaboration limits. Do not suppress this error merely because another rule
reports plausible coverage: an incomplete design model invalidates that
evidence.
