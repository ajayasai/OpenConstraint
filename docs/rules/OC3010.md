# OC3010 — invalid-io-delay

**Default severity:** error

**Category:** I/O

Reports a `set_input_delay` or `set_output_delay` whose command shape is missing
the delay/target operands or whose delay is not a finite numeric literal. A
complete command containing a Tcl-dynamic delay expression is a warning because
the safe backend intentionally does not evaluate it; missing or non-numeric
static values are errors.

Use a finite literal in the statically audited SDC, or run the trusted OpenSTA
adapter when dynamic Tcl is intentional. A delay rejected by this rule does not
satisfy the input/output coverage obligation.

The rule validates one literal number, not arithmetic expressions, units,
external-device timing, or the electrical correctness of the value.
