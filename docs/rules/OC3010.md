# OC3010 — invalid-io-delay

**Default severity:** error

**Category:** I/O

Reports a `set_input_delay` or `set_output_delay` whose command does not have
exactly one delay operand and one target collection, or whose delay is not a
finite numeric literal. OpenSTA rejects additional positional target
collections instead of merging them. A complete command containing a
Tcl-dynamic delay expression is a warning because the safe backend intentionally
does not evaluate it; malformed, missing, or non-numeric static values are
errors.

Use a finite literal in the statically audited SDC, or run the trusted OpenSTA
adapter when dynamic Tcl is intentional. A delay rejected by this rule does not
satisfy the input/output coverage obligation.

The rule validates one literal number, not arithmetic expressions, units,
external-device timing, or the electrical correctness of the value.
