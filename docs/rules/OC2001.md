# OC2001 — invalid-clock-period

**Default severity:** error

**Category:** clocks

Reports a clock with no finite, positive modeled period.

Primary clocks require a valid `-period`. A generated clock may derive a period
from a reachable source/master clock plus a supported divide, multiply,
combinational, or three-edge/edge-shift transform. An invalid transform or
unresolvable source relationship can therefore also leave its period unknown.

Fix the value and generated-clock relationship, then inspect OC2010/OC2011.
The beta does not interpret units or arbitrary Tcl numeric expressions, so
provide a literal numeric value in the static input.
