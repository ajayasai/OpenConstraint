# OC5002 — mode-exception-drift

**Default severity:** note

**Category:** modes

Reports exception-topology additions or removals between the first supplied
mode and each later mode.

The compared signature contains exception kind, resolved `-from`/`-to` sets,
ordered through collections, and normalized qualifiers. Qualifiers retain
rise/fall selection, setup/hold and start/end applicability, multicycle or
min/max-delay values, multicycle reset markers, explicit-side/scope-resolution
state, and clock-group relation where relevant. Evidence reports added and
removed counts. Review the JSON/HTML mode data and record why functional, scan,
test, or low-power policy differs.

Raw command spelling and duplicate multiplicity are not compared. Unsupported
SDC semantics, path feasibility, and full exception precedence remain outside
the signature. This is a review prompt rather than proof that two modes are
semantically equivalent.
