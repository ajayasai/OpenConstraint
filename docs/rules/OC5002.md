# OC5002 — mode-exception-drift

**Default severity:** note

**Category:** modes

Reports exception-topology additions or removals between the first supplied
mode and each later mode.

The compared signature contains exception kind plus resolved `-from` and `-to`
sets. Evidence reports added and removed counts. Review the JSON/HTML mode data
and record why functional, scan, test, or low-power policy differs.

The beta signature does not compare through collections, numeric multicycle or
min/max values, edge qualifiers, setup/hold flags, or command text. This is a
review prompt rather than proof that two modes are semantically equivalent.
