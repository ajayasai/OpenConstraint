# OC4012 — conflicting-multicycle

**Default severity:** error

**Category:** exceptions

Reports different multicycle multipliers assigned to the same setup or hold
phase on the same normalized scope. Scope comparison includes resolved from/to
objects, ordered through collections and rise/fall qualifiers, plus the
effective start/end relationship. OpenSTA's default is normalized to `-end`
for setup-only or combined setup/hold constraints and to `-start` for hold-only
constraints. Evidence records both multipliers and the earlier source location.

Keep one multiplier per phase/scope, or narrow the object or edge qualifiers so
the intended relationships are distinct.

The rule detects deterministic static conflicts. It does not implement complete
vendor precedence, enumerate feasible paths, evaluate case analysis, or prove
that either exception is correct. Exact-scope `-reset_path` history is applied;
broader subset/superset reset precedence remains outside this rule.
