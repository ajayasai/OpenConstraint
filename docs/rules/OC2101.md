# OC2101 — unconstrained-endpoint

**Default severity:** error

**Category:** coverage

Reports sequential data endpoints whose instance has no clock pin reached by a
defined clock in the current mode. Evidence includes the full set and a bounded
sample.

Create or repair primary/generated clocks and their targets so each intended
sequential clock pin is reached. Also verify Liberty sequential metadata, the
selected top, and structural connectivity.

An endpoint is identified from Liberty sequential groups and data pins, with a
conservative naming fallback for some cells. Reachability is structural and can
both miss unsupported connectivity and over-approximate conditional clock
paths. This rule does not calculate setup or hold timing.
