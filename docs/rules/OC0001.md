# OC0001 — malformed-sdc

**Default severity:** error

**Category:** loading

Reports unbalanced Tcl/SDC grouping, malformed decoded words (including invalid
Unicode escapes), and option/operand grammar errors in one of the nine modeled
constraint commands or the `current_design` context assertion. Grammar errors
include foreign options, missing option values, and other shapes that cannot be
interpreted deterministically.

Raw Tcl command-substitution grouping is limited to 64 bracket levels. Crossing
that limit rejects the complete document without a parsed command prefix, and
all command chunking, word splitting, and selector recognition enforce the same
boundary before an attacker-sized lexical context stack can accumulate.

It also reports a static SDC source that is not valid UTF-8 or exceeds the
16 MiB (16,777,216-byte) cumulative source budget for one logical mode. The
budget is shared by that mode's files in supplied order and accepts the exact
limit. A file that crosses the remaining budget or fails UTF-8 decoding rejects
the whole mode: commands from that file and every earlier file are discarded,
later files are not opened, and no parsed prefix is credited. Direct in-memory
parsing applies the same all-or-nothing limit to the complete source.

Malformed grouping can change the meaning of every following token, while a
grammar error can change which word is an option, operand, or target. The
affected command does not mutate modeled state, and the affected mode's trusted
coverage is forced to `0.0/F`. Fix the Tcl structure and command grammar before
reviewing downstream findings.

The static lexer tracks braces, quotes, brackets, comments, continuations, and
command boundaries; it does not execute Tcl. Source-boundary failures are
reported at the start of the rejected source. A single command retains at most
50,000 words and is rejected without a partial command if that limit is
crossed. OC0001 is not a complete Tcl
syntax validator and cannot identify semantic errors inside otherwise balanced
dynamic Tcl code. Commands outside the allowlist use `OC0003`; unsupported
query semantics use `OC1003` or `OC1004`.
