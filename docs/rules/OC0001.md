# OC0001 — malformed-sdc

**Default severity:** error

**Category:** loading

Reports unbalanced Tcl/SDC grouping, including an unexpected or unterminated
brace/bracket and an unterminated quoted word.

Malformed grouping can change the meaning of every following token, so
downstream results from the document are not trustworthy. Fix the lexical Tcl
structure before reviewing other findings.

The static lexer tracks braces, quotes, brackets, comments, continuations, and
command boundaries; it does not execute Tcl. OC0001 is not a complete Tcl
syntax validator and cannot identify semantic errors inside otherwise balanced
dynamic Tcl code.
