# OC0001 — malformed-sdc

**Default severity:** error

**Category:** loading

Reports unbalanced Tcl/SDC grouping, malformed decoded words (including invalid
Unicode escapes), and option/operand grammar errors in one of the nine modeled
constraint commands or the `current_design` context assertion. Grammar errors
include foreign options, missing option values, and other shapes that cannot be
interpreted deterministically.

Malformed grouping can change the meaning of every following token, while a
grammar error can change which word is an option, operand, or target. The
affected command does not mutate modeled state, and the affected mode's trusted
coverage is forced to `0.0/F`. Fix the Tcl structure and command grammar before
reviewing downstream findings.

The static lexer tracks braces, quotes, brackets, comments, continuations, and
command boundaries; it does not execute Tcl. OC0001 is not a complete Tcl
syntax validator and cannot identify semantic errors inside otherwise balanced
dynamic Tcl code. Commands outside the allowlist use `OC0003`; unsupported
query semantics use `OC1003` or `OC1004`.
