# OC2002 — implicit-clock-waveform

**Default severity:** note

**Category:** clocks

Reports a valid primary clock that omits `-waveform` and therefore uses the
modeled default `{0, period/2}` waveform.

This is review information, not an error. Add an explicit waveform only when
the intended active edges differ or when project policy requires the intent to
be written down. Avoid adding redundant text solely to silence the tool.

Use `--no-implicit-waveform-note` to disable this note for a run. Generated
clocks do not emit OC2002.
