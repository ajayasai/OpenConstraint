# OC1003 — dynamic-query

**Default severity:** error

**Category:** queries

Reports an object query whose pattern depends on a Tcl variable or nested
dynamic expression. The non-executing static backend preserves this syntax as text and
does not execute it.

Replace the query with a static collection when practical, generate a flattened
SDC artifact in a trusted build stage, or validate the dynamic source through a
separately controlled flow. Do not suppress the finding merely because the same
file works in an interactive Tcl tool.

Dynamic queries remain visible as unresolved query-health obligations and force
the affected mode's trusted aggregate coverage to `0.0/F`, because their match
result and every dependent constraint scope are unknowable statically.
