# OC4011 — multicycle-setup-hold-pair

**Default severity:** warning

**Category:** exceptions

Reports either of these review conditions for a setup multiplier greater than
1:

- one command applies the same multiplier to both setup and hold; or
- a setup-only multiplier `N` has no hold-only multiplier `N-1` on the same
  normalized structural and edge-qualified scope.

The pairing scope includes resolved from/to objects, ordered through
collections and their rise/fall qualifiers, plus from/to/end transition
qualifiers. Setup and hold `-start`/`-end` values are allowed to differ so the
usual setup-end/hold-start pairing can match. State setup and hold separately
when the usual same-clock `N`/`N-1` convention matches the actual clock
relationship.

A multicycle `-reset_path` removes earlier exact-scope multicycle candidates
before pairing analysis.

The convention is a review heuristic, not a universal timing law. The rule does
not enumerate paths, derive all cross-clock edge relationships, apply full STA
precedence, validate every explicit start/end combination, or prove that a
multicycle path is functionally valid.
