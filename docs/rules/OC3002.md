# OC3002 — output-delay-missing

**Default severity:** warning

**Category:** I/O

Reports output or inout ports not matched by any supported `set_output_delay` in
the current mode.

Add interface-appropriate output delays referenced to the correct capture
clock, or document and model an intentional exception. Review bus and wildcard
scope carefully.

The beta checks matched-port coverage only. It does not validate the delay
number, clock relationship, min/max pairing, transition direction, or external
device requirement.
