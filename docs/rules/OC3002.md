# OC3002 — output-delay-missing

**Default severity:** warning

**Category:** I/O

Reports output or inout ports without a finite, direction-valid
`set_output_delay` whose clock reference is absent or resolves in the current
mode.

Add interface-appropriate output delays referenced to the correct capture
clock, or document and model an intentional exception. Review bus and wildcard
scope carefully.

The beta validates that the value is finite, the port direction is compatible,
and an explicit clock resolves. Separate diagnostics cover those failures,
min/max completeness, and replacement without `-add_delay`. It does not prove
the value, edge/transition selection, or external-device requirement is
correct.
