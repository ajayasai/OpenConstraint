# OC2005 — invalid-clock-waveform

**Default severity:** error

**Category:** clocks

Reports an explicit primary-clock `-waveform` whose edge list cannot be used by
the static model. The list must contain finite numeric values, have an even
number of entries, and be strictly increasing. When the clock has a valid
period, no edge may be more than two periods from time zero.

Replace the list with the intended ordered rise/fall edge pairs and confirm that
the clock period is correct. An invalid explicit waveform is retained as an
error condition; it is not relabeled as an implicit 50% waveform by `OC2002`.

This rule checks numeric shape and a bounded period relationship. It does not
prove that the selected edges match a protocol, generated-clock phase, or
sign-off engine interpretation.
