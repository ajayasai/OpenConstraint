# OC3001 — input-delay-missing

**Default severity:** warning

**Category:** I/O

Reports input or inout ports that are not clock targets and are not matched by
any supported `set_input_delay` in the current mode.

Add interface-appropriate input delays, or document and model an intentional
asynchronous interface using the flow's timing policy. Merely adding a blanket
delay to silence the rule can conceal protocol mistakes.

The beta checks coverage of the port collection, not delay value, clock
reference, min/max pairing, edge choice, or interface correctness. Inout ports
participate in both input and output obligations.
