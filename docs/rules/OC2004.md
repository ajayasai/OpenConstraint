# OC2004 — multiple-active-clocks

**Default severity:** warning

**Category:** clocks

Reports sequential clock pins reached by more than one modeled clock in the
same mode. Evidence maps each affected pin to its clock names.

Multiple clocks can be intentional for muxed or test clocks, but require an
explicit exclusivity policy or separate scenario analysis. Review clock groups,
mode partitioning, and clock target scope.

Clock propagation is structural and conservative: it passes through modeled
combinational cells without evaluating conditional Liberty arcs or case
analysis. The rule may therefore over-approximate clocks that are mutually
exclusive in functional logic.
