# OC0003 — unevaluated-tcl-command

**Default severity:** error

**Category:** loading

Reports dynamic command dispatch or any top-level command outside the exact
static allowlist of nine constraint commands plus a literal `current_design`
context directive. This includes `$command ...`, `if`, loops, procedures,
`source`, `eval`, `set`, `return`, and project-specific helpers.
It also includes an otherwise supported selector substituted into a scalar
option such as `-name`/`-comment`, or into an effective scalar delay/multiplier
positional: Tcl evaluates that selector to a value, so retaining its source
spelling would change the outer command's meaning.
Such commands can create, suppress, or rewrite timing constraints at runtime,
so silently ignoring even an apparently harmless helper could produce a clean
but incomplete audit.

Any affected mode receives coverage score `0.0` and grade `F`. Flatten trusted
constraints to the documented static SDC subset before auditing, or use the
optional OpenSTA validation path inside an appropriate OS sandbox. OC0003 does
not mean the Tcl is invalid; it means its effective constraint behavior was not
evaluated by the static model. Nested supported selectors may still produce
independent query evidence, but the outer command never mutates modeled state.
