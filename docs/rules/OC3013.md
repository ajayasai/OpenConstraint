# OC3013 — io-delay-min-max-incomplete

**Default severity:** warning

**Category:** I/O

Reports a finite modeled I/O-delay relationship for which explicit `-min` or
`-max` coverage is present but its opposite analysis sense is absent. Commands
without either flag are normalized as applying to both senses. Separate
commands can complete the pair when they have the same delay kind, port,
resolved clock set, clock edge, and rise/fall data-transition scope.
Completeness is evaluated after non-additive replacement and `-add_delay`
replay, so superseded relationships cannot satisfy or otherwise affect the
final completeness result.

Add the complementary constraint, or omit both flags when one value
intentionally applies to min and max analysis. Review the actual early/late
external-device requirements rather than copying a value merely to silence the
warning.

This is a structural completeness check. It does not determine whether the min
and max values, clock edge, or transition polarity are physically correct.
